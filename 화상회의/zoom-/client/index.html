SW개발보안 1팀 프로그램

보안 회의 콘솔

회의 참여, 생성, 보안 설정을 한 화면에서 관리합니다.

회의 대기 중 보안 점검 모드
이 화면에서 점검하는 보안 항목:
  • 회의실 ID allow-list 입력 검증
  • 암호학적 난수 기반 회의실 ID 생성
  • Jitsi Meet 임베드 시 P2P 비활성화 옵션 전달
  • 초기 오디오·비디오 음소거 및 초대 기능 제한 옵션 전달
  • iframe sandbox와 no-referrer 정책 적용
  • 보안 헤더는 secure_static_server.py에서 HTTP 응답 헤더로 적용
  • E2EE와 로비 모드는 외부 회의 엔진 지원 범위 안에서 요청
